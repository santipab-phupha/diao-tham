# Diao Tham mark

Original geometric **D** monogram for Diao Tham. The connected upright and
rounded bowl form one closed silhouette; the inner counter is transparent.
The four-color gradient uses blue as its main area, then warm red/yellow and
green around the outer curve. It contains no filters, masks, fonts or scripts.

- `diao-tham-mark.svg`: transparent mark, 64 × 64 viewBox.
- `favicon.svg`: same silhouette on a white rounded tile for browser tabs.
- `diao-tham-wordmark.svg`: transparent horizontal lockup, 320 × 80 viewBox,
  with the D mark, dark-ink name and small tagline. Its text remains editable
  and uses Segoe UI / system-ui / Arial fallbacks; it has no external font or
  image dependency. Typeface metrics may vary slightly by platform.

Palette: `#4285f4`, `#ea4335`, `#fbbc05`, `#34a853`.

The mark is an original Diao Tham design inspired by a familiar four-color
palette. It is not a Google logo or an indication of Google affiliation.
